## Summary

同期によって削除対象になったリモートファイルを指定したディレクトリへ退避します。

## Parameters

| Name         | Type   | Required | Description                                                                                                      |
| ------------ | ------ | -------- | ---------------------------------------------------------------------------------------------------------------- |
| `archive_to` | `Path` | ✅        | 削除対象のファイルを退避させるディレクトリを指定する。                                                                                      |
| `extensions` | `str`  |          | 対象とする画像ファイルの拡張子をセミコロン区切りで指定する。<br>デフォルトは `'*'`。<br>大文字小文字は区別しない。`'*'` を指定するとすべての拡張子が対象となる。<br>例: `jpg;jpeg;png;` |
