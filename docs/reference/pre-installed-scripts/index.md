# Pre-installed scripts

このセクションでは、あらかじめ組み込まれているスクリプトの一覧とその機能について説明します。

- [Hello World](hello-world.md): 単純に指定された文字列を出力するスクリプトです。
- [Print Synced Paths](print-synced-paths.md): 同期対象のディレクトリやファイル情報を出力します。
- [Image Resize & Backup](image-resize-and-backup.md): 画像ファイルをリサイズして指定ディレクトリにバックアップします。
- [Archive Before Removal](archive-before-removal.md): 同期で削除されるファイルを事前に指定ディレクトリへ退避します。
