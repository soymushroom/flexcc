## Summary

画像ファイルをリサイズして指定したディレクトリにバックアップします。

## Parameters

| Name            | Type                                                                  | Required | Description                                                                                                                                                                              |
| --------------- | --------------------------------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `export_to`     | `Path`                                                                | ✅        | リサイズされた画像を保存するディレクトリを指定する。                                                                                                                                                               |
| `extensions`    | `str`                                                                 |          | 対象とする画像ファイルの拡張子をセミコロン区切りで指定する。<br>デフォルトは `'jpg; jpeg; png; gif; bmp; webp; tiff; tif; heic; heif; '`。大文字小文字は区別しない。例: `jpg;jpeg;png;`                                                     |
| `mode`          | `Literal['percentage', 'long_side', 'short_side', 'width', 'height']` |          | リサイズ方法を指定するモード。<br>デフォルトは `'percentage'`。<br> - `'percentage'`: パーセンテージ指定<br> - `'long_side'`: 長辺を基準にリサイズ<br> - `'short_side'`: 短辺を基準にリサイズ<br> - `'width'`: 幅を固定<br> - `'height'`: 高さを固定 |
| `value`         | `int`                                                                 |          | `mode` に応じたリサイズの基準値。デフォルトは `100`。                                                                                                                                                        |
| `jpeg_quality`  | `int`                                                                 |          | JPEG 保存時の品質。デフォルトは `92`。                                                                                                                                                                 |
| `allow_enlarge` | `bool`                                                                |          | 元の大きさより拡大することを許容する。デフォルトは `False`。                                                                                                                                                       |
